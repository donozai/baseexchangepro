# BaseExchangePro Landing Page

Static, responsive landing page for BaseExchangePro.xyz.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Select **GitHub Actions** (or deploy from the `main` branch if preferred).
5. For a custom domain, set the repository Pages custom domain to `baseexchangepro.xyz`.
6. Configure DNS at your domain provider according to GitHub's current Pages instructions.

## Important

The merchant form is frontend-only. It shows a demo success state and does not send personal data anywhere. Connect it to a real backend/form provider before accepting applications.

The copy intentionally avoids guarantees of profit, fixed rates, licensing claims, or official exchange partnerships.
